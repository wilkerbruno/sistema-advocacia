# Esta pasta foi substituída pelo WAHA

O serviço customizado que estava aqui (`server.js`, Node.js +
`whatsapp-web.js`) foi **substituído pelo WAHA** (https://waha.devlike.pro),
um projeto open-source mantido especificamente para isso: já vem com
painel de conexão via QR code, chave de API, reconexão automática etc. —
mais confiável do que manter na mão a mesma coisa que esse projeto já
resolve.

**Você não precisa fazer nada com esta pasta.** Se ela nunca chegou a ser
publicada como um serviço no EasyPanel (provavelmente o caso, já que a
troca aconteceu antes disso), pode simplesmente apagar a pasta
`whatsapp-bridge/` inteira do seu repositório. Se por acaso você já tinha
subido um serviço a partir dela no EasyPanel, pode excluir esse serviço
por lá também — ele não é mais usado por nada no sistema.

O passo a passo atual (com o WAHA) está no `PENDENCIAS.md`, seção -4, na
raiz do projeto.
